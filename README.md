# Fish_opt_krg — демонстрационный стенд

Подробная схема переноса на существующую LUNA: [FISH_STORE_BLUEPRINT_RU.md](FISH_STORE_BLUEPRINT_RU.md).

Отдельный проект для показа Fish_opt_krg. Каталог из 326 позиций, штрихкоды, категории, единицы, вес, страна и цены перенесены из предоставленного прайса Fish Dream от 26.09.2026 в `catalog_2026-09-26.csv`. Внутренние телефоны и контакты из оригинального файла в проект не переносились. Филиалы, сотрудники, поставщики, клиенты, продажи и остатки вымышлены. В анкете подтверждены пять филиалов, команда из 20 человек, работа в 1С и цель привлечения/удержания клиентов.

## Кассовое оборудование

**Подтверждённая пользователем модель: ПОРТ-100Ф.** На предоставленном фото автономная касса со встроенной печатью, дисплеем покупателя и клавишами «ПИ», «ИТОГ», «ШТРИХ», «КАРТА», «1СЕК–6СЕК». Для интеграции нужно определить доступный интерфейс и порт конкретного экземпляра, версию прошивки и его текущий режим работы с 1С. Производитель описывает связь с ПК и режим фискального регистратора, но подключение конкретного аппарата ещё не проверено. Этот стенд не отправляет команды кассе, не печатает фискальные чеки и не передаёт данные ОФД.

## Запуск

```bash
cd fish-opt-krg
python3 app.py
```

Откройте http://127.0.0.1:8091. Требуется только Python 3.9+; база `fish_price_demo.sqlite3` создаётся при первом запуске. Для сброса демо остановите сервер и удалите только этот файл. Прежняя демо-база `fish_demo.sqlite3` оставлена отдельно и не используется.

При первом запуске создаются 5 филиалов, 326 товаров, 20 сотрудников, 4 поставщика, 12 клиентов, 150 вымышленных продаж за десять дней, движения и остатки. Себестоимость **не указана** в прайсе и оценивается для демо как 70% розничной цены; она не является реальной закупочной ценой. Ставка бонусов 3% тоже демонстрационная. Стенд работает локально, на `127.0.0.1`. В интерфейсе доступны каталог с поиском по штрихкоду, остатки, гости, продажи, движения, сотрудники, поставщики, отчёт по филиалам, управление акциями и статус оборудования. Приход и списание меняют остатки; продажа уменьшает остаток и начисляет бонусы клиенту. Повтор запроса продажи с одинаковым `request_id` не создаёт второй чек. Лояльность единая для пяти филиалов. CSV `GET /export/stock.csv` — пример выгрузки для согласования обмена с 1С, а не готовая интеграция с 1С или фискальная касса.

### Акции и скидки в демо

Четыре заполненных значения столбца «Акция» в исходном файле совпадают с обычной ценой. Они импортируются **выключенными заготовками**, а не действующими скидками. В форме «Правило акции» можно выбрать товар, филиал или всю сеть, даты, минимальное количество и **либо** новую цену, **либо** процент. Правило нужно явно включить. При продаже система проверяет дату по `Asia/Almaty`, точку и количество; если подходит несколько правил, выбирает самое выгодное клиенту, без сложения скидок. В чеке сохраняются исходная сумма, скидка, сумма к оплате и ID применённого правила. Демо-бонус 3% рассчитывается от суммы после скидки. Старые учебные чеки не пересчитываются при изменении акции. Это локальный прототип: согласованные правила должны быть отдельно перенесены на каноническую кассу и учётное ядро LUNA.

Проверка расчёта: `PYTHONPYCACHEPREFIX=/tmp/fish-pycache python3 -m unittest -v test_promotions.py`.

Для реальной эксплуатации нужно подтвердить актуальность прайса от 26.09.2026, закупочные цены, адреса филиалов, правила бонусов, интерфейс и настройки ПОРТ-100Ф, протокол обмена с 1С.
